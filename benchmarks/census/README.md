# The conformance census has moved

It is at <https://github.com/troybrandonc-bit/machine-testimony/tree/main/census>,
and the standing register it produces is at
<https://machinetestimony.org/register/>.

## Why it left

The census assesses eight agent systems against the Testimony Record's
requirements, and OMEM is one of the eight. While it lived here, the party
being assessed was hosting the assessment, publishing it, and holding the only
copy of the rubric. Every word of the conflict-of-interest section was true and
none of it survived being filed in the subject's own repository.

It is the same error that put the specification in this repository until 5
September, for the same reason, and it gets the same fix. The specification, the
validator, the conformance corpus and now the census belong to the research
programme. OMEM is a subject of them.

Nothing about the verdicts changed in the move: the census digest is
`sha256:b66ecf0de51fcfece1e1527043d47ec60fbd32735a4c85f8f441d4fe45c88d75`
before and after.

## If a verdict about OMEM is wrong

Open a pull request against `census/subjects/omem.json` in that repository, or
write to troy@machinetestimony.com naming the requirement and where to look.
That door is the same one everybody else gets, which is the point of it not
being here.
